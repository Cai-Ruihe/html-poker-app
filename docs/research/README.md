## Evidence rules

- Record the retrieval date and link primary/official sources where possible.
- Separate facts, inferences, unknowns, and product decisions.
- Inspect source code before making implementation claims about an open-source project.
- Treat product pages as evidence of advertised behavior, not proof of internal implementation.
- Recheck time-sensitive browser support, provider terms, prices, laws, service reachability, and regional availability before relying on them.
- Promote an adopted conclusion into the decision register/ADR/owning PRD; do not leave controlling requirements only in research prose.

When new evidence materially changes product direction, perform pivot research before resuming detailed requirement grilling.
