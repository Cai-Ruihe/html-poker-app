# Third-party notices

The Normal build currently distributes React, React DOM, Scheduler, Archivo, and Bricolage Grotesque. Their exact production versions and declared licences are inspectable with `pnpm licenses:prod`.

The human-readable [distribution licence bundle](apps/web/public/THIRD-PARTY-LICENSES.txt) is source-controlled under the web application's public assets and is copied into every Normal build. Dependency or asset changes must update that file before release; package metadata alone is not sufficient evidence that a distributable contains required notices.
